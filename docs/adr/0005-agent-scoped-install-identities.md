# Count agent-scoped local CLI identities, with separate harness adoption

A unique reported install is an agent under one random, agent-scoped local CLI identity, not a person, a verified physical device or a Harness copy. Under that identity, projects, global scope, Harness Profiles, reinstalls, updates and added Harnesses do not create new logical-agent totals. Identity state stays outside shareable project lockfiles; no shared cross-agent device identifier, local path or Harness-setting value is transmitted. Another local CLI identity, such as one on a different machine or after state reset, can count again, and client reports are not fraud-proof.

Count actual direct and Dependency Agent installations, distinguishing their origin without sending private parent-source identifiers. Deduplicate the logical total by Agent plus installation identity and Harness adoption by that same pair plus Harness. Multiple omp profiles remain the same Harness for these counters. A later direct install of a Dependency must not create a second logical total. Cumulative adoption is not active usage; removal does not justify advertising an accurate active-install population.

Use the combined automatic-sharing opt-out already selected: disable install reports (automatic registration no longer exists, see [ADR 0008](0008-authenticated-submissions-without-auto-registration.md)) when `DO_NOT_TRACK` or `DISABLE_TELEMETRY` is set, including child-installer telemetry. Keep private/local source identifiers, destination paths, credentials and search queries out of reporting. WorkOS website login is not required for anonymous direct installation or these counts, and is not linked to installation identities.
